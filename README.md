# Variable-Horizons
The variants handler mod for GTNH

Introduces many variants you can use to spice up the pack, including Infinite Power, Dimension Lock, No Rocket, No Quest Rewards, Void Island, Void World, and many more. 

Even better, you can pair variants together (as long as they're not incompatible)! Why not do a Dimension Lock on a Void Island? Even better, why not do it while you have Infinite Power and the recipes for wireless energy hatches and covers to use it? 

Some variants introduce helpful commands, especially if you want to make a server! For example, if you want to run a Skyblock server, the player can do a simple /island create (requires permission level 1), and get their own, personal island, 8,000 blocks away! Or in a different dimension!

Variants are easily configurable using the new gui in the singleplayer world selection screen, though, servers will unfortunately have to use either the /variants commands or change the active variants in the config.
Upon toggling a variant, you will need to restart the game most of the time.
